## 2. 플로우 목적과 연결

비공개 확인 대화상자, 변경 안내, 자물쇠 표시를 확인한다.

다른 사용자의 저장 라이브러리에서 제거된다는 문구가 있다. 상대 계정과 직접 링크 접근은 재현하지 않았다.

- 상위 흐름: [List detail](<../ANALYSIS.md>)
- 하위 흐름: 없음.
- 폴더 위치: `medium/flows/Library/List detail/Making a list private`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: 공개 리스트의 Make list private 메뉴에서 시작한다.
- 종료: 타인 저장 제거 경고 뒤 완료 토스트·자물쇠 표시가 생긴다.
- 관련 흐름: [Deleting a list](<../Deleting a list/ANALYSIS.md>) · [Creating a list](<../../Creating a list/ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
