## 2. 플로우 목적과 연결

리스트 다운로드 요청의 정지 아이콘과 항목별 완료 표시를 비교한다.

기기 오프라인 상태에서 실제 본문을 열어 보지 않았다. 캐시 만료·일부 실패도 미확인이다.

- 상위 흐름: [List detail](<../ANALYSIS.md>)
- 하위 흐름: 없음.
- 폴더 위치: `medium/flows/Library/List detail/Downloading a list`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: 글 4개 리스트의 다운로드 컨트롤에서 시작한다.
- 종료: 정지 모양을 거쳐 리스트·각 글 다운로드 아이콘이 채워진다.
- 관련 흐름: [Downloading an image](<../../../Home/Story detail/Sharing a story/Downloading an image/ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

## 6. 공식 도움말과 API 대조

공식 자료는 현재 문서이며 과거 캡처와 시점이 다를 수 있다. 아래 기능 설명의 범위만 대조했으며 내부 API나 제품 전체 규칙을 확인한 것은 아니다.

- [Create and manage lists](https://help.medium.com/hc/en-us/articles/214993247-Create-and-manage-lists): 글을 여러 리스트에 선택해 저장할 수 있고 공개 리스트 자체는 Saved lists에 저장한다. 리스트 설명은 선택 입력이다. 비공개 리스트는 본인만 접근하며 기본 Reading list는 삭제할 수 없다. 리스트별 글 메모·재정렬·제거와 다운로드 버튼 재탭을 통한 오프라인 사본 제거를 설명한다. 캡처에 없는 실행 결과는 검증 완료로 기록하지 않는다. [공통 문서 대조](<../../../../SOURCES.md#lists>).
- [Become a Medium Member](https://help.medium.com/hc/en-us/articles/115004545567-Become-a-Medium-Member): Member와 Friend 등급 및 오디오·오프라인 혜택을 설명한다. 캡처의 SGD 표시 가격을 현재 모든 지역 가격으로 일반화하지 않는다. [공통 문서 대조](<../../../../SOURCES.md#membership>).

화면에서 관찰한 값·메뉴와 문서에 없는 세부 상태는 구분한다. 미수록 오류·권한·실패 분기는 아래 질문으로 남긴다.

- [API 검토](<../../../../SOURCES.md#api>). 이 흐름의 내부 endpoint·요청·응답·DB 스키마는 확인하지 않았다.

## 7. 데이터 모델링 시사점

다음은 관찰에 기반한 구현 후보다. Kostolany의 기능 채택·스키마·업무 정책으로 확정하지 않는다.

- 단계 01: 리스트 항목에 메모·순서 부여
- 단계 02: 리스트 요청과 항목별 로컬 캐시 상태
- 단계 03: UI 완료와 오프라인 가용성 별도 검증

## 8. 미확인 사항과 검토 질문

**원본에 없는 분기·남은 범위:** 중단·부분 실패·재다운로드·캐시 삭제·저장 공간 부족·비행기 모드.

- 단계 01: 글 추가 과정 미수록·카드 다운로드 아이콘 의미
- 단계 02: 네트워크 실패·중단·부분 다운로드
- 단계 03: 비행기 모드 재현·캐시 만료 미확인
- 같은 계정·같은 빌드에서 시작 상태를 맞춘 뒤 정상·취소·실패·재진입 결과를 검증해야 한다.
