## 2. 플로우 목적과 연결

리스트의 특정 기사에 메모를 작성하여 카드 위 주석으로 표시하는 흐름을 확인한다.

이 메모는 리스트 항목 메모이며 작성자에게 보내는 private note 기능과 다르다.

- 상위 흐름: [List detail](<../ANALYSIS.md>)
- 하위 흐름: 없음.
- 폴더 위치: `medium/flows/Library/List detail/Adding a note`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: 리스트 내 특정 글의 Add note에서 시작한다.
- 종료: 글 미리보기 위 입력 후 리스트의 해당 글 위에 메모가 나타난다.
- 관련 흐름: [Removing a story](<../Removing a story/ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
