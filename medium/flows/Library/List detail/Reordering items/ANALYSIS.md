## 2. 플로우 목적과 연결

리스트 관리에서 드래그 순서를 바꾸고 Done 후 카드 순서 반영을 확인한다.

재정렬 전후 항목은 동일하다. 메모를 순서가 아닌 항목 정체성에 연결할 필요가 있다.

- 상위 흐름: [List detail](<../ANALYSIS.md>)
- 하위 흐름: 없음.
- 폴더 위치: `medium/flows/Library/List detail/Reordering items`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: 리스트 메뉴에서 Reorder items를 연다.
- 종료: 핸들로 표시된 새 순서 뒤 일반 목록의 앞 두 글 순서가 일치한다.
- 관련 흐름: [List detail](<../ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
