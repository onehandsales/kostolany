## 2. 플로우 목적과 연결

이름·선택 설명·Private를 가진 생성 폼에서 새 빈 리스트가 추가되는 결과를 확인한다.

이름 60자·설명 280자 카운터가 있다. 초과·중복·공백 이름 검증은 수록되지 않았다.

- 상위 흐름: [Library](<../ANALYSIS.md>)
- 하위 흐름: 없음.
- 폴더 위치: `medium/flows/Library/Creating a list`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: Your lists의 New list에서 시작한다.
- 종료: 이름 입력·설명 공란·Private Off 뒤 새 빈 리스트 카드가 보인다.
- 관련 흐름: [Saving a story](<../../Home/Story detail/Saving a story/ANALYSIS.md>) · [List detail](<../List detail/ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

- 공식 문서 확인: 6절에서 기능별 출처와 적용 한계를 대조한다. 이 화면의 내부 API 호출은 관찰하지 않았다.
- 설계 가정: 빈 리스트와 구성 항목 별도 생성. 구현 후보이며 확정 스키마·정책이 아니다.
- 미확인: 공개 조회·영속성

#### 모델링 영향

- 후보와 근거: 빈 리스트와 구성 항목 별도 생성. 위의 확인된 상태와 표시 데이터를 근거로 검토한다.
- 확정 전 확인: 공개 조회·영속성. 화면 관찰만으로 필수값·권한·트랜잭션을 확정하지 않는다.

## 5. 업무 규칙과 데이터 변화

이름 60자·설명 280자 카운터가 있다. 초과·중복·공백 이름 검증은 수록되지 않았다.

| 단계 | 관찰된 상태·값 | 근거의 한계 |
| --- | --- | --- |
| 01 | 기본 목록에 글 존재 — 3 stories·자물쇠 | 글 추가 경로·정렬 |
| 02 | 생성 전 입력 — 이름0/60, 설명0/280, Private 꺼짐 | 이름 공백·중복 검증 |
| 03 | 이름만 입력해 생성 가능 표시 — About mindfulness 17/60, 설명 없음, Private 꺼짐 | 서버 필수값·초과 검증 |

위 표는 보이는 상태 변화다. 성공 토스트가 있어도 외부 계정의 가시성·영수증·서버 저장을 독립 검증한 것은 아니다.

화면에서 관찰한 값·메뉴와 문서에 없는 세부 상태는 구분한다. 미수록 오류·권한·실패 분기는 아래 질문으로 남긴다.
