# Filtering digest 플로우 분석

검토 상태: **R2 누락·내용 재검토 완료(정적 캡처 범위)**. 실제 이미지 재확인 **4/4단계**. 계정 재현은 수행하지 않았다.

관찰은 Gummble 캡처에서 직접 본 내용, 문서 확인은 현재 공식 도움말, 설계 가정은 우리 구현 후보를 뜻한다. 버튼의 존재·성공 안내·실제 서버 결과를 구분한다.

## 2. 플로우 목적과 연결

최근 다이제스트 10개 중 다른 날짜를 고르고 해당 기사 묶음으로 전환한다.

June 12→June 8 변화는 선택한 다이제스트 날짜다. Today's highlights 제목만으로 오늘 생성된 것으로 해석하지 않는다.

- 상위 흐름: [Library](<../ANALYSIS.md>)
- 하위 흐름: [Digest settings](<Digest settings/ANALYSIS.md>)
- 폴더 위치: `medium/flows/Library/Filtering digest`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: Digest 날짜 선택에서 시작한다.
- 종료: 최근 10개 중 June 8을 선택·Done 후 해당 날짜 글이 보인다.
- 관련 흐름: [Digest settings](<Digest settings/ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
