## 2. 플로우 목적과 연결

프로필에서 월간 조회·읽음 그래프, 특정 날짜, 글별 Lifetime 통계를 확인한다.

월간 11/2와 글별 0/0이 동시에 보여 집계 차이가 있다. 현재 도움말의 갱신 주기와 과거 화면 문구도 다르다.

- 상위 흐름: [Profile](<../ANALYSIS.md>)
- 하위 흐름: 없음.
- 폴더 위치: `medium/flows/Profile/Story stats`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: 프로필의 View stats에서 시작한다.
- 종료: 월간 UTC 11/2, 날짜 선택, Lifetime 글별 0/0을 확인한다.
- 관련 흐름: [Profile](<../ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

- R2 보완 관찰·해석: Lifetime에는 별도 기간·Updated daily·Latest 필터가 있다. 월간 전체 집계 11/2와 이 글 행의 0/0 차이는 범위·시점·캐시 어느 원인인지 확인되지 않았다.
- 단계 간 변화: 통계 그래프 날짜 선택 → 글별 Lifetime 통계. 현재 관찰값: Latest, The Silence between Notes, Views0·Reads0. 캡처 사이의 정확한 조작·요청은 미기록이다.

#### 동작과 데이터

- 화면 관찰: 위 입력값·컨트롤·표시 상태를 확인했다. 정적 캡처이므로 실제 요청 성공·서버 영속성은 별도 증거가 필요하다.
- 공식 문서 확인: 6절에서 기능별 출처와 적용 한계를 대조한다. 이 화면의 내부 API 호출은 관찰하지 않았다.
- 설계 가정: 서로 다른 집계 범위·갱신 시점 검증. 구현 후보이며 확정 스키마·정책이 아니다.
- 미확인: 월간11/2와 글별0/0 차이 원인 미확인

#### 모델링 영향

- 후보와 근거: 서로 다른 집계 범위·갱신 시점 검증. 위의 확인된 상태와 표시 데이터를 근거로 검토한다.
- 확정 전 확인: 월간11/2와 글별0/0 차이 원인 미확인. 화면 관찰만으로 필수값·권한·트랜잭션을 확정하지 않는다.

## 5. 업무 규칙과 데이터 변화

월간 11/2와 글별 0/0이 동시에 보여 집계 차이가 있다. 현재 도움말의 갱신 주기와 과거 화면 문구도 다르다.

| 단계 | 관찰된 상태·값 | 근거의 한계 |
| --- | --- | --- |
| 01 | 발행 글 없음 — Alex Smith, 0 followers·1 following | 미발행 초안 포함 여부 |
| 02 | 일별 통계 시각화 — Jun 1–13 2025 UTC, Updated daily, Views11·Reads2 | 과거 캡처의 View·Read 계산식·중복 제거·집계 지연은 미확인. 현재 도움말의 5초·30초 및 사용자/일 중복 제거 규칙을 과거에 소급 적용하지 않는다. |
| 03 | 특정 날짜 선택 — Jun 12 2025, Views11·Reads2 | 선택한 일자 집계·전체 합계 라벨 관계 |
| 04 | 글별 누적 통계 표시 — Latest, The Silence between Notes, Views0·Reads0 | 월간11/2와 글별0/0 차이 원인 미확인 |

위 표는 보이는 상태 변화다. 성공 토스트가 있어도 외부 계정의 가시성·영수증·서버 저장을 독립 검증한 것은 아니다.

## 6. 공식 도움말과 API 대조

공식 자료는 현재 문서이며 과거 캡처와 시점이 다를 수 있다. 아래 기능 설명의 범위만 대조했으며 내부 API나 제품 전체 규칙을 확인한 것은 아니다.

- [Stats](https://help.medium.com/hc/en-us/articles/215108608-Stats): 현재 문서는 Views를 5초 이상, Reads를 30초 이상으로 설명하며 사용자·일 단위로 중복 제거한다. 월간 통계는 시간별 갱신이고 Lifetime은 발행 첫 달에는 시간별, 이후 매일 갱신한다. 캡처의 월간 Updated daily와 차이가 있으며 이 정의를 과거 캡처에 소급 적용하지 않는다. [공통 문서 대조](<../../../SOURCES.md#stats>).

차이: 캡처는 Updated daily, 현재 공식 Stats는 월간 통계를 시간별 갱신으로 안내한다. 현재 문서의 지표 정의를 과거 캡처에 소급 적용하지 않는다.

- [API 검토](<../../../SOURCES.md#api>). 이 흐름의 내부 endpoint·요청·응답·DB 스키마는 확인하지 않았다.
