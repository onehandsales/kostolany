## 2. 플로우 목적과 연결

아이콘 선택 화면의 기본 선택과 Friend of Medium 잠금 안내를 확인한다.

실제 아이콘 변경 성공 흐름은 없다. 잠금 안내와 제공 가능한 행동의 범위를 문서에 구분한다.

- 상위 흐름: [Settings](<../ANALYSIS.md>)
- 하위 흐름: 없음.
- 폴더 위치: `medium/flows/Profile/Settings/Custom app icon`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: Settings의 Custom app icon에서 시작한다.
- 종료: Wordmark Black 선택과 Friend 업그레이드 잠금 안내만 확인한다.
- 관련 흐름: [Subscribing to Medium](<../../../Onboarding/Subscribing to Medium/ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

## 5. 업무 규칙과 데이터 변화

실제 아이콘 변경 성공 흐름은 없다. 잠금 안내와 제공 가능한 행동의 범위를 문서에 구분한다.

| 단계 | 관찰된 상태·값 | 근거의 한계 |
| --- | --- | --- |
| 01 | 주요 설정 진입점 — Appearance System default 선택 | 각 계정·결제 하위 화면 미수록 |
| 02 | 아이콘 변경 기능 잠금 안내 — Wordmark Black 선택, 다른 아이콘 흐림 | 실제 OS 아이콘 변경·구독별 현재 조건 |

위 표는 보이는 상태 변화다. 성공 토스트가 있어도 외부 계정의 가시성·영수증·서버 저장을 독립 검증한 것은 아니다.

## 6. 공식 도움말과 API 대조

공식 자료는 현재 문서이며 과거 캡처와 시점이 다를 수 있다. 아래 기능 설명의 범위만 대조했으며 내부 API나 제품 전체 규칙을 확인한 것은 아니다.

- [Become a Medium Member](https://help.medium.com/hc/en-us/articles/115004545567-Become-a-Medium-Member): Member와 Friend 등급 및 오디오·오프라인 혜택을 설명한다. 캡처의 SGD 표시 가격을 현재 모든 지역 가격으로 일반화하지 않는다. [공통 문서 대조](<../../../../SOURCES.md#membership>).

멤버십 문서는 등급 배경을 확인하는 자료다. 아이콘 잠금·선택지·OS 변경 결과를 직접 설명하는 문서는 이번 대조에서 확인하지 못했다.

- [API 검토](<../../../../SOURCES.md#api>). 이 흐름의 내부 endpoint·요청·응답·DB 스키마는 확인하지 않았다.
