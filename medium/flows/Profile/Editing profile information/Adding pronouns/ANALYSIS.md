## 2. 플로우 목적과 연결

대명사 검색과 he·him 선택 후 상위 프로필 폼으로 반환하는 흐름을 분석한다.

최종 프로필 Save 화면 이후 결과는 이 자식 흐름에 없다. Done과 프로필 저장을 구분한다.

- 상위 흐름: [Editing profile information](<../ANALYSIS.md>)
- 하위 흐름: 없음.
- 폴더 위치: `medium/flows/Profile/Editing profile information/Adding pronouns`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: 프로필 편집의 Pronouns 0/4에서 시작한다.
- 종료: he·him 선택 후 2/4가 상위 폼에 반영된다. Save 이전에 흐름이 끝난다.
- 관련 흐름: [Editing profile information](<../ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
