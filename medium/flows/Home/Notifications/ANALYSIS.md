## 2. 플로우 목적과 연결

홈 알림 아이콘에서 팔로워·리스트 변경·박수 알림 목록으로 이동한다.

알림의 과거 날짜는 캡처일이 아니다. 왼쪽 녹색선의 읽음 의미와 읽음 전환은 확인되지 않았다.

- 상위 흐름: [Home](<../ANALYSIS.md>)
- 하위 흐름: 없음.
- 폴더 위치: `medium/flows/Home/Notifications`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: Home 알림 아이콘에서 목록으로 연결된다.
- 종료: 팔로워·저장 리스트 새 글·박수 알림과 일부 Follow 버튼이 보인다.
- 관련 흐름: [Changing notification settings](<../../Profile/Settings/Changing notification settings/ANALYSIS.md>) · [Following an author](<../Story detail/Author detail/Following an author/ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

## 6. 공식 도움말과 API 대조

공식 자료는 현재 문서이며 과거 캡처와 시점이 다를 수 있다. 아래 기능 설명의 범위만 대조했으며 내부 API나 제품 전체 규칙을 확인한 것은 아니다.

- [Adjust email preferences](https://help.medium.com/hc/en-us/articles/115004745947-Adjust-email-preferences): 이메일 알림 종류와 Digest 주기 설정을 설명한다. 앱의 푸시 토글 전체 계약을 대신하지 않는다. [공통 문서 대조](<../../../SOURCES.md#email>).

이메일 알림 유형은 이벤트 분류의 비교 자료다. 앱 알림의 녹색선 의미·읽음 처리·정렬 계약은 확인하지 않았다.

- [API 검토](<../../../SOURCES.md#api>). 이 흐름의 내부 endpoint·요청·응답·DB 스키마는 확인하지 않았다.
