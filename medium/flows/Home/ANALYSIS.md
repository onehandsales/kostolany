## 2. 플로우 목적과 연결

For you 카드 목록과 스크롤, Featured의 빈 상태 및 콘텐츠 상태를 비교한다.

Featured가 채워지는 사이의 팔로우 동작은 없다. 같은 화면 상태 모음이 단일 연속 세션임을 보장하지 않는다.

- 상위 흐름: 없음. Gummble의 최상위 흐름이다.
- 하위 흐름: [Publishing a story](<Publishing a story/ANALYSIS.md>) · [Refine recommendations](<Refine recommendations/ANALYSIS.md>) · [Story detail](<Story detail/ANALYSIS.md>) · [Notifications](<Notifications/ANALYSIS.md>)
- 폴더 위치: `medium/flows/Home`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: For you 탭의 카드 목록에서 시작한다.
- 종료: 스크롤 뒤 Featured의 빈 상태와 채워진 상태가 수록된다. 팔로우 중간 조작은 없다.
- 관련 흐름: [Refine recommendations](<Refine recommendations/ANALYSIS.md>) · [Story detail](<Story detail/ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

- 설계 가정: 발행물 편집 추천과 개인 추천 피드 구분. 구현 후보이며 확정 스키마·정책이 아니다.
- 미확인: 직전 빈 상태 이후 팔로우 변화는 화면만으로 확정 불가

- 확정 전 확인: 직전 빈 상태 이후 팔로우 변화는 화면만으로 확정 불가. 화면 관찰만으로 필수값·권한·트랜잭션을 확정하지 않는다.

## 5. 업무 규칙과 데이터 변화

Featured가 채워지는 사이의 팔로우 동작은 없다. 같은 화면 상태 모음이 단일 연속 세션임을 보장하지 않는다.

| 단계 | 관찰된 상태·값 | 근거의 한계 |
| --- | --- | --- |
| 01 | 추천 기사 목록 — For you 활성. 작가·제목·요약·썸네일·날짜·박수·응답 수 표시 | 추천 알고리즘·개인화 저장·카드 전체 클릭 영역 |
| 02 | For you 하단 목록 — 다른 기사 카드와 집계 표시 | 페이지네이션·새로고침·중복 제거 |
| 03 | 팔로우 발행물의 추천 글이 없다는 안내 — No featured stories | 빈 상태의 서버 원인·팔로우 개수 |
| 04 | Featured 콘텐츠가 있는 상태 — Featured 선택. 저장 아이콘 표시 | 직전 빈 상태 이후 팔로우 변화는 화면만으로 확정 불가 |

위 표는 보이는 상태 변화다. 성공 토스트가 있어도 외부 계정의 가시성·영수증·서버 저장을 독립 검증한 것은 아니다.

공식 자료는 현재 문서이며 과거 캡처와 시점이 다를 수 있다. 아래 기능 설명의 범위만 대조했으며 내부 API나 제품 전체 규칙을 확인한 것은 아니다.

화면에서 관찰한 값·메뉴와 문서에 없는 세부 상태는 구분한다. 미수록 오류·권한·실패 분기는 아래 질문으로 남긴다.
