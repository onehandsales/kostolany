## 2. 플로우 목적과 연결

같은 글에 문자 스타일·인용·글머리 목록·구분선을 적용한 시각적 변화를 비교한다.

스타일 변경은 캡처에서 확인되지만 내부 블록 스키마·모든 서식 조합·저장 여부는 확인되지 않았다.

- 상위 흐름: [Publishing a story](<../ANALYSIS.md>)
- 하위 흐름: 없음.
- 폴더 위치: `medium/flows/Home/Publishing a story/Changing text format`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: 제목·문단·사진이 있는 초안에서 시작한다.
- 종료: 문자 스타일·인용·목록·구분선의 화면 변화를 확인한다. 최종 발행 결과는 없다.
- 관련 흐름: [Publishing a story](<../ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
