## 2. 플로우 목적과 연결

본문 @ 입력에서 이름 검색·동명이인 후보·사용자 멘션 삽입까지 확인한다.

녹색 이름 삽입은 확인된다. 상대방 알림 수신과 발행 시점의 멘션 처리까지 확인된 것은 아니다.

- 상위 흐름: [Publishing a story](<../ANALYSIS.md>)
- 하위 흐름: 없음.
- 폴더 위치: `medium/flows/Home/Publishing a story/Mentioning a user`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: 기존 초안의 새 문단에서 @를 입력한다.
- 종료: 검색 후보에서 이름이 녹색 텍스트로 삽입된다.
- 관련 흐름: [Publishing a story](<../ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

- 공식 문서 확인: 6절에서 기능별 출처와 적용 한계를 대조한다. 이 화면의 내부 API 호출은 관찰하지 않았다.
- 설계 가정: 본문 텍스트 범위와 참조 사용자 연결. 구현 후보이며 확정 스키마·정책이 아니다.
- 미확인: 알림 발송 시점·대상 삭제 시 처리

#### 모델링 영향

- 후보와 근거: 본문 텍스트 범위와 참조 사용자 연결. 위의 확인된 상태와 표시 데이터를 근거로 검토한다.
- 확정 전 확인: 알림 발송 시점·대상 삭제 시 처리. 화면 관찰만으로 필수값·권한·트랜잭션을 확정하지 않는다.
