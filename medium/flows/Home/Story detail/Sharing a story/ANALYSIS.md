## 2. 플로우 목적과 연결

기사의 공유 카드, 링크 복사 토스트, 가로 공유 행동을 분석한다.

Copy link 결과만 보인다. Friend Link와 외부 공유 앱은 버튼 존재만 확인되었다.

- 상위 흐름: [Story detail](<../ANALYSIS.md>)
- 하위 흐름: [Downloading an image](<Downloading an image/ANALYSIS.md>)
- 폴더 위치: `medium/flows/Home/Story detail/Sharing a story`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: 기사 공유 버튼에서 시작한다.
- 종료: 공유 카드와 Copy link 성공 토스트, Save image 진입점이 보인다.
- 관련 흐름: [Downloading an image](<Downloading an image/ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

- 단계 간 변화: 링크 복사 피드백 → 이미지 저장 행동 노출. 현재 관찰값: 동일 카드. 캡처 사이의 정확한 조작·요청은 미기록이다.

#### 동작과 데이터

- 화면 관찰: 위 입력값·컨트롤·표시 상태를 확인했다. 정적 캡처이므로 실제 요청 성공·서버 영속성은 별도 증거가 필요하다.
- 공식 문서 확인: 6절에서 기능별 출처와 적용 한계를 대조한다. 이 화면의 내부 API 호출은 관찰하지 않았다.
- 설계 가정: 공유 카드 내보내기 작업. 구현 후보이며 확정 스키마·정책이 아니다.
- 미확인: 사진 권한 요청·저장 형식

#### 모델링 영향

- 후보와 근거: 공유 카드 내보내기 작업. 위의 확인된 상태와 표시 데이터를 근거로 검토한다.
- 확정 전 확인: 사진 권한 요청·저장 형식. 화면 관찰만으로 필수값·권한·트랜잭션을 확정하지 않는다.

## 5. 업무 규칙과 데이터 변화

Copy link 결과만 보인다. Friend Link와 외부 공유 앱은 버튼 존재만 확인되었다.

| 단계 | 관찰된 상태·값 | 근거의 한계 |
| --- | --- | --- |
| 01 | 멤버 전용 기사 읽기 화면 — 5 min read, Apr 30 2025, Jordan Gibbs, 18K 박수·834 응답 | 현재 계정 권한·본문 게이트·집계 정확값 |
| 02 | 공유 미리보기 — 읽기 시간·제목·부제·작가·Medium 표시 | Friend Link 권한·외부 앱 전송 결과 |
| 03 | 복사 완료 안내 — Link copied | 클립보드 실제 URL·유효 범위 |
| 04 | Save image 전체 표시 — 동일 카드 | 사진 권한 요청·저장 형식 |

위 표는 보이는 상태 변화다. 성공 토스트가 있어도 외부 계정의 가시성·영수증·서버 저장을 독립 검증한 것은 아니다.
