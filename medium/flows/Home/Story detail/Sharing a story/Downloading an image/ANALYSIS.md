## 2. 플로우 목적과 연결

공유 카드 Save image와 이미지 저장 성공 토스트를 확인한다.

다운로드 대상은 기사 본문 원본 사진이 아니라 공유용 카드 이미지다. 실제 사진 보관함 파일은 재현하지 않았다.

- 상위 흐름: [Sharing a story](<../ANALYSIS.md>)
- 하위 흐름: 없음.
- 폴더 위치: `medium/flows/Home/Story detail/Sharing a story/Downloading an image`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: 공유 카드의 Save image가 보이는 상태에서 시작한다.
- 종료: Image saved to library 토스트를 확인한다.
- 관련 흐름: [Sharing a story](<../ANALYSIS.md>) · [Downloading a list](<../../../../Library/List detail/Downloading a list/ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.

## 6. 공식 도움말과 API 대조

공식 자료는 현재 문서이며 과거 캡처와 시점이 다를 수 있다. 아래 기능 설명의 범위만 대조했으며 내부 API나 제품 전체 규칙을 확인한 것은 아니다.

- [About Friend Links](https://help.medium.com/hc/en-us/articles/360006543813-About-Friend-Links): Friend Link는 일반 URL과 접근 조건이 다르다. 생성자의 자격에 따라 조건이 달라 버튼 노출만으로 권한을 확정하지 않는다. [공통 문서 대조](<../../../../../SOURCES.md#friend>).

Friend Link 문서는 공유 권한의 배경 자료다. Save image의 파일 형식·사진 권한·저장 해상도는 확인하지 못했다.

- [API 검토](<../../../../../SOURCES.md#api>). 이 흐름의 내부 endpoint·요청·응답·DB 스키마는 확인하지 않았다.
