## 2. 플로우 목적과 연결

플레이어에서 언어별 음성 목록을 열어 Hans를 선택하고 복귀한다.

한국어 음성 선택지가 있어도 기사 자동 번역이나 한국어 본문 지원의 증거가 아니다.

- 상위 흐름: [Listening to a story](<../ANALYSIS.md>)
- 하위 흐름: 없음.
- 폴더 위치: `medium/flows/Home/Story detail/Listening to a story/Changing voice`
- 부모·자식은 Gummble 탐색 분류다. 모든 자식 흐름이 반드시 실행되는 순차 단계나 런타임 화면 트리를 뜻하지 않는다.

### 진입 조건과 확인된 종료 범위

- 진입: 플레이어의 Select a voice 메뉴에서 시작한다.
- 종료: Emma 선택 → Hans 선택 → 플레이어 복귀가 수록된다. 실제 음성은 듣지 않았다.
- 관련 흐름: [Listening to a story](<../ANALYSIS.md>)
- 관련 흐름 링크는 기능의 연결점이다. 서로 다른 캡처를 같은 계정·같은 시각의 연속 실행으로 합치지 않는다.
