- 배치·타이포·여백·이미지 비율/crop·아이콘·색상·상태·뒤로 복귀를 점검한다. 글자·이미지 겹침과 잘림은 가로 overflow 검사만으로 대신하지 않는다.
- 시각적 목표와 접근성 규칙을 함께 충족한다. 작은 원본 아이콘도 48×48 이상 조작 영역을 확보하고 글자 확대를 일괄 차단하지 않는다. 불가피한 차이는 숨기지 않고 근거·영향을 기록한다.
- 원본에 없는 오류/재시도·폼 경계·mock 인증 결과는 자체 설계로 표시한다. 정적 캡처만으로 실제 Google 성공·저장 시점·전환 동작을 관찰했다고 쓰지 않는다.
- 실제 차이나 미확인 항목이 남아 있으면 대상 전체의 100% 일치를 선언하지 않는다. 임의의 유사도 점수로 차이를 완료 처리하지 않는다.

### 실행과 전달

- 기존 `http://localhost:8081`을 보존하고 desktop·작은 모바일 폭에서 실제 조작과 console 오류를 확인한다.

- iOS·Android 실행/빌드/화면 비교를 각각 기록한다. 브라우저·Jest·JS/Hermes 번들과 실제 native 실행/빌드를 구분한다.

- 장애 재현용 mock 설정을 정상 기본값으로 복원한다. 실제 서비스 연동·배포 완료로 표현하지 않는다.
