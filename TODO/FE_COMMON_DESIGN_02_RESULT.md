## 발견과 수정

수정 전 실제 Android 라이브러리의 `Your library`와 배너 문구가 원본보다 얇았다. 코드에서는 `fontWeight: '600'`을 지정했지만 설치된 React Native0.86.3의 `ReactFontManager.getTypeface`는 명시한 기본 시스템 fontFamily를 `nearestStyle`로 처리한다. 이 경로는700 미만을 일반 스타일로 분류한다. 원본 폰트 부재와 별도로 확인한 현재 Android의 굵기 처리 차이다.

- [공통 토큰](../FE/src/shared/theme/tokens.ts)에 `fontWeights.semibold`를 추가했다. Android는700, iOS/web은 기존600을 유지한다.
- 공통 `pageTitle`·`sectionTitle`과 [라이브러리](../FE/src/features/bookmarks/LibraryScreen.tsx)의 배너 강조 문구에 적용했다. 서체·크기·행간·터치 영역은 유지한다.
- 수정 후 실제 Android Home 제목과 Library 제목·배너에서 굵기 변화를 확인했다. 원본과 같은 폰트/정확한 weight를 확보했다는 뜻은 아니다.
- 기존 reference PNG, 앱 데이터 계약, native 소스, 의존성·잠금 파일은 수정하지 않았다. 스타일 갱신 후 Home 화면을 확인하고 Library에 다시 진입했다. 이 확인을 사용자 테스트 글의 앱 재시작 영속성 검증으로 해석하지 않는다.

### 후속 사용자 확인과 편집기 아이콘 — 2026-11-26

기사 읽기 화면의 잘림/겹침, Save to 시트의 표시/닫기, 긴 제목·본문과 키보드 가림 확인을 안내한 뒤 사용자가 “다 정상이기는 해”라고 보고했다. 이3항목은 사용자 확인 통과로 기록하며 에이전트의 재실행이나 원본 동일성 판정과 구분한다.

동시에 사용자는 편집기 사진을 제공하며 B 옆 기울임 버튼이 세로선처럼 보이고 다음 버튼의 의미가 불명확하다고 지적했다. 제공 사진과 현재 코드를 확인한 결과, 위쪽 도구 줄은 굵게(B)·기울임(I)·링크(↗)·키보드 닫기(⌄) 순서다. B/I에 같은 일반 텍스트 스타일을 사용하므로 I가 세로선처럼 보인다. 사진의 링크 버튼은 선택 범위가 없는 상태에서 비활성으로 흐리게 표시되는 현재 규칙에 대응한다.

사진 확인 시점에는 **서식 도구의 아이콘 식별성을 미해결**로 분류했다. 굵은 B·기울어진 I·링크를 나타내는 명확한 아이콘이 보정 대상이었다. S183 원본도 직접 열람했으나 해당 캡처에는 아래 문단 서식 도구만 보여 위쪽 B/I/링크 줄의 원본 동일성을 확정하지 않는다. 이후 보정 결과는 아래와 같다.

### 서식 도구 아이콘 후속 보정 — 2026-11-26

- 기울임: 양끝 획이 있고 오른쪽으로 기울어진 I 모양.
- 링크: 서로 연결된 사슬 모양.

### 편집기 아이콘 크기·저장 표시·하단 정렬 — 2026-11-26

사용자가 위쪽 아이콘 크기, Saved의 중앙 이탈, @를 포함한 하단 도구의 왼쪽 쏠림을 지적했다. 화면에 한글 설명을 표시하지 않는 지시는 유지했다.

- 하단 도구는 선택 시 색상만 변경하도록 분리했다. 이전에는 공통 녹색 텍스트 스타일의16 크기가 덮어써져 선택한 도구가 작아졌다.
- 헤더의 왼쪽·중앙·오른쪽에 같은 비율의 폭을 배정해 Saved를 중앙에 둔다. 저장 실패 재시도 문구는 중앙 영역에서 줄바꿈하고 오른쪽 조작도 가용 폭을 넘으면 줄바꿈할 수 있다.
- 하단 가로 도구 줄은 남는 폭을 채워7개 버튼 간격을 고르게 배분한다. 좁은 화면에서 각 버튼의 최소 터치 폭을 줄이지 않고 기존 가로 스크롤을 유지한다. @는 멘션 삽입 버튼이다.
