# 기존 Goal 1~53의 작업 계약

**Parity9 추가 검토(2026-11-24):** [C40 표시 보완·기존 선택/저장 계약 검증](../FE_MEDIUM_PARITY_09_RESULT.md#additional-review). 단일 입력/문서 모델을 유지해 native 인용 전용 구간/구분선을 부분 보완했다. C40~45 작성→재개→발행 관련90 tests 통과와 실제 키보드/web 미검증을 분리한다. 혼합 문단 배치 잔여를 이유로 기존 G36~39 계약을 임의 확대하지 않는다.

**Parity9(2026-11-24):** [작성·초안·발행 계약의 실제 적용](../FE_MEDIUM_PARITY_09_RESULT.md). 기존 G36~39의 mock·자동 저장·문서/선택·발행 멱등 계약을 유지한다. 화면별 R과 C40~45 소비 검증, Q04/Q06 원본 근거 판정·native 배치/기기 잔여를 별도 기록했다. 과거 계약과 결과는 삭제하지 않는다.

**2026-11-24 최신 추적:** [Parity1~8 잔여 정리](../FE_MEDIUM_PARITY_01_08_REVIEW.md). 원본 R/T/U/C와 배정은 보존한다. 정책·Digest 이미지/비교 집계와 본문 미리보기 연결을 보완했으며, 목록 메모·발행 다운로드는7/8의 후속 해결로 연결했다. 원본 미수록 정책·기기·제외를 구현 결함과 구분한다.

**묶음7·8 추가 검토:** [결과](../FE_MEDIUM_PARITY_08_RESULT.md#additional-review). 계정이 비활성인 동안 확정된 목록 소속/원문 철회도 사본에 반영하고 복원 시 자동 재다운로드하지 않는다. Library/Profile/발행 reader의 Save to·편집·응답 초안은 화면 이탈 때 폐기하며 확정 상태는 유지한다. 기존 mock 계약의 연결 보완이며 Medium 미확인 동작을 새로 확정하지 않는다.

각 화면 요구가 참조하는 실제 작업 문장이다. 제목이나 결과 파일 존재만으로 포함 판정하지 않는다. Goal1~21은 선행 기반/1차 클론 이력이며 최신 세부 기능 담당은22~53이다. 원본 관찰과 기존 요구가 충돌하는 곳은 보완 작업으로 남긴다.
