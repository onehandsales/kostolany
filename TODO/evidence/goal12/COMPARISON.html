프로필에서 설정 진입

원본은 우측 상단 톱니 아이콘, 구현은 설정 문자 버튼이다. 프로필 편집과 계정 표시를 유지했다.

설정 상단

중앙 제목·왼쪽 뒤로·회색 섹션·흰 메뉴 행·구분선·하단 탭을 참고했다. 읽기 설정과 기본 수준은 자체 기능이며 원본 Appearance 기능을 구현하지 않았다.

설정 하단의 로그아웃

원본의 Sign out 진입을 필요한 계정 섹션으로 연결했다. 다른 설정과 앱 버전 메뉴는 이번 범위가 아니다.

로그아웃 확인

배경 dim·중앙 확인·취소/확인을 참고한 기존 Goal 10 UI를 재사용했다. 모의 계정 이름·처리 중·실패 재시도는 자체 설계이며 native 시스템 alert와 다르다.

우리 앱의 추가 상태와 검증 캡처

4단계 기본 수준·선택 시트·오류·재시도·A/B 설정·기사 기본값은 자체 설계다. CSS 글자 2배는 OS 글자 확대 검증이 아니며 Safe Area·VoiceOver/TalkBack·native 뒤로 가기와 포커스는 미검증이다.
