프로필과 편집 진입

이름·원형 자리·외곽선 편집 버튼 위계. 우리 앱은 모의 계정 안내와 로그아웃을 추가하고 작성자 통계·팔로우·Stories/Lists/About 탭은 제외했다.

이름·소개 입력

상단 닫기/제목/저장, 회색 입력, 우측 50/160 카운터. 사진·대명사·별도 About 편집은 제외했다. 소개는 여러 줄 입력 높이 120px, 안내·취소·오류·추가 저장은 자체 설계다.

소개 표시

원본 About의 세리프 소개와 프로필 이름을 참고했다. 우리 앱은 한글 기본 글꼴과 프로필 내 소개 영역을 사용하며 회원 기간과 사진은 없다.

빈 소개

원본은 About의 회색 빈 안내와 Add a short bio 링크. 우리 앱은 짧은 안내와 동일한 프로필 편집 진입을 사용한다.

Settings의 편집 진입 관찰

원본 Settings에 Edit profile이 있다. 이번 Goal은 프로필 직접 편집만 연결하고 설정 화면 확장은 Goal 12로 남겼다. 같은 설정 화면을 구현했다는 비교가 아니다.
